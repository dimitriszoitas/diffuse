Available tools

    Set up Figma desktop

    1. Open the design file you want to review in Figma desktop.
    2. Switch to Dev Mode and enable the desktop MCP server in the inspect panel.
    3. Connect here, then copy a frame link from that same file into your AI review.

    The desktop connection uses the file open in Figma. Desktop setup guide ↗

    Figma’s hosted MCP server requires an approved client from its MCP Catalog. Hosted Figma sign-in is not available in Diffuse. Connection requirements ↗

    When you run a review with a Figma link, the retrieved design context is sent to your selected AI provider with your page screenshots. Tokens stay separate from shared review files.

    GitHub reviews

    Give feedback on a pull request or bring someone’s feedback onto your preview. Your role can change from one review to the next.

    Connected accounts

    Loading…

    Sign in with GitHub to share feedback and native screenshots or recordings on pull requests.

    Public repositories are enabled by default. Including private repositories requests GitHub’s repo permission, granting broad read/write access to public and private repositories your account can access. Diffuse still checks that its app is installed on each chosen repository.

    GitHub opens in a separate sign-in window. Your repository administrator may need to approve the Diffuse app.

    Connecting does not publish feedback. A publish preview shows the repository, its visibility, and the findings you are about to share. People can read published feedback in GitHub without installing Diffuse.
