# Diffuse 0.14.0

Journey recordings show where each click happens. After a run, ask about any step and explore an alternative route without replacing the original attempt.

- A translucent yellow halo and click pulse appear in journey recordings and short comment recordings. Journey clicks include a brief visible lead-in before navigation.
- **Ask about this step** answers from the saved observations, action summaries, and outcomes. Supporting steps link back to the evidence. Up to 20 questions are retained with each journey.
- **Fork journey…** prepares an editable alternative route. **Run alternative route** returns to the original starting URL and creates a separate run and recording. Existing app data is not reset.
- The extension popup has four actions: **Start Diffuse**, **Load Review**, **Review Reports**, and **Settings**. Start Diffuse also reopens an active review and restores capture access when needed.
- The sidebar separates **Review with AI**, **Journey Testing with AI**, and **Diff View**, with a clear comment shortcut legend and Settings at the bottom. Short recordings start inside comments; Stop recording remains available during a capture.

Follow-up questions use your saved Anthropic key and can incur API charges. They send the recorded journey context and selected step screenshot, not the full video. A question itself never performs browser actions. Alternative routes run only after you start them.

Replace the files in your existing keyed Diffuse folder and reload the extension at `chrome://extensions`. Saved reviews remain in the same Chrome profile. See [the journey guide](../journey-reviews.md) for the workflow and its limits.

Validation uses local test pages and simulated model responses, including a full multi-page run, a follow-up answer, a fork through a different path, retained original evidence, and recorded click feedback. Live-model judgement quality is not established by those tests.
