# Diffuse 0.17.0 — Claude agents pilot

Journey testing can now use two persistent Claude Managed Agents in your own Anthropic account. **Diffuse Journey User** follows your task and simulated persona. **Diffuse Journey Evaluator** reviews the recorded evidence and continues the discussion afterwards. Both use exactly **`claude-fable-5` with `max` effort**.

## Enable it

Update your existing Diffuse installation with this ZIP and reload the extension. Open **Settings → AI → Journey testing**, select **Claude agents**, review the spending limit, and choose **Set up journey agents**. Your saved Anthropic API key provisions both definitions and their environment. They appear in Claude Console after setup succeeds. Setup creates no journey sessions and sends no page evidence.

## Behavior

- Each browser action is proposed against a fresh observation and checked by Diffuse before execution.
- The journey and evaluator have separate roles and tools. The evaluator can read saved screenshots but cannot operate the website.
- Pause discards stale proposals. Stop cancels pending work. An uncertain request is not automatically replayed.
- Follow-up questions reuse the saved evaluator session and its remaining budget.
- The configurable default is $2 per journey, split 75% for the attempt and 25% for evaluation/chat. An in-flight request may finish over its allocation. New journeys and continuations get a new budget.
- Direct journeys remain available. Screenshot audits and Jira title suggestions keep using the regular configured model.

Managed session events and screenshots are retained at Anthropic. Recordings stay on the device. Removing a local review or API key does not delete provider-side data. See the [setup and data-removal guide](../managed-agents.md).

## Validation status

Local mocked API tests cover setup, event pagination, budgets, account isolation, action validation, separate evaluation, interrupted requests, and continuing chat. Browser fixtures cover settings and journey UI. **No live paid Claude agent journey has yet been verified in the user's account.** This is an opt-in pilot, not a claim of improved real-world journey accuracy.
