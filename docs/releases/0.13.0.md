# Diffuse 0.13.0

## Give AI a task to try

Open **Test a journey** in the review sidebar and describe a goal, such as “Add Oat milk to the ingredients table with ml as its unit.” Diffuse discovers visible controls, follows the task through multiple pages on the same website, and checks the observed outcome.

Add optional success criteria, test data, or specific steps. The journey uses your existing Anthropic key and model. Keep the reviewed tab visible; Pause, Resume, and Stop remain available.

## Watch what happened

Each attempt keeps a silent recording of the reviewed tab, screenshots, and notes for its steps. **Watch this step** jumps to the corresponding moment in the movie. Download the full WebM recording when you want to keep or share it. Pausing the journey pauses recording too.

Results distinguish completion, observed failure, blocked progress, and an inconclusive outcome. They show page visits, click attempts, backtracking, and five AI assessments: discoverability, clarity, effort, feedback, and recovery. Assessments include their reasoning, confidence, and supporting steps; untested dimensions remain unscored.

Accept useful suggestions as normal review comments. Each accepted finding keeps the page, screenshot, and reproduction path for Jira, GitHub, or review exports. The full journey movie stays in local history and can be downloaded separately.

## Scope and verification

This first version operates one tab on one website origin, at the selected viewport, with a maximum of 30 actions or ten minutes. It uses rendered page evidence. Login challenges, external sites, sensitive controls, unsupported widgets, and uncertain outcomes can stop a run. Use a test environment: the journey can submit forms and create records.

AI assessments are suggestions to inspect, not a human usability study or proof of backend correctness. Each decision sends page evidence to Anthropic and can incur API charges. The full recording is not sent to the model. See the [journey guide](../journey-reviews.md) and [privacy notice](../PRIVACY.md).

Browser validation covers a real multi-page ingredient-creation flow, native sidebar controls, screenshots, recording playback and seeking, pause/resume, accepted findings, and saved history. The test uses controlled model responses; it does not measure live-model judgment quality.

Ordinary recordings also release their busy state as soon as saving finishes. The short-lived retry cache no longer prevents selecting a Diff reference for another minute.

## Update

Unzip **Diffuse-0.13.0.zip**. For an official installation from 0.10.2 onward, replace the files in the existing **Diffuse** folder, click **Reload** in `chrome://extensions`, and refresh the reviewed page. Keep the same installation to retain reviews and settings.

For a new installation, enable Developer mode in `chrome://extensions`, choose **Load unpacked**, and select the **Diffuse** folder. From 0.10.1 or earlier, export reviews before installing separately and import them with **Load review**.
