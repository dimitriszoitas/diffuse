# Diffuse 0.12.0

Give feedback, make the change, and review the result in one shared pull request.

## Two sides of the review

- **Give feedback:** select findings from a saved review, choose the PR and preview, and inspect the text, captured evidence, repository visibility, and commit before publishing. Diffuse maintains one summary with native GitHub screenshots and recordings.
- **Work through feedback:** read the summary in GitHub without installing Diffuse, or use **Load from a GitHub PR** to restore the findings on your chosen preview at their recorded route and viewport. After making a change, capture and inspect updated evidence before sharing **Ready for recheck**.
- **Review the change:** capture a fresh screenshot or a short recording before sharing **Verified** or **Still present**. The PR shows the original and updated captures, who checked them, and the associated commit. A new commit makes earlier checks historical; it does not automatically mark feedback as fixed.

These are activities within a review. A reviewer can be a designer, stakeholder, or manager; the person working through feedback can be a designer or engineer. The same person can switch between both activities.

## Evidence and control

Updated screenshots and silent recordings are previewed before sharing. Recordings can be up to 30 seconds, with shorter clips sometimes needed to fit the sharing limit. Capturing or connecting an account does not publish anything. Interrupted publications resume from saved receipts; uncertain status updates can be confirmed without creating another check.

Original captures and shared history remain intact when a finding is remapped or revisited. The original publisher can update authored feedback; collaborators with repository write access can share evidence and status checks. Read access supports reading and loading reviews. Previously published findings remain when a selected subset is updated.

## Connect GitHub

Open **Settings → GitHub reviews** and sign in. Public repositories are enabled by default. **Include private repositories** explicitly requests GitHub's broader `repo` permission for public and private repositories your account can access. Diffuse also requires its GitHub App to be installed on each chosen repository; an owner or administrator may need to approve that installation. No personal access token or personal server is required.

The person reviewing confirms the preview-to-commit association. Diffuse does not prove that a deployment serves a particular commit, merge PRs, approve code, or bypass website logins. See the [GitHub review guide](../github-review.md) and [privacy notice](../PRIVACY.md).

## Install or update

New installation: unzip **Diffuse-0.12.0.zip**, enable Developer mode in `chrome://extensions`, choose **Load unpacked**, and select the **Diffuse** folder.

From an official **0.10.2 or 0.11.0** installation, replace the files in the existing Diffuse folder, click **Reload** in `chrome://extensions`, and refresh reviewed pages. Keep the same installation to retain its identity, reviews, and settings.

From **0.10.1 or earlier**, export reviews first, keep the old installation intact, install this release separately, and import with **Load review**. Reconnect optional accounts and disable the old copy after checking the imports.
