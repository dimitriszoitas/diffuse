# Diffuse 0.17.1

## Journey discussion recovery

- Discuss stopped or blocked agent journeys even when no usability evaluation completed.
- Start the evaluator on the first question using the original reserved allowance, then reuse it for follow-ups.
- Preserve specific browser stop reasons in the result, step details and chat.
- Explain unavailable or uncertain evaluator sessions without inventing scores or silently resetting a budget.
- Preserve existing reviews, recordings, settings and agent connections when replacing an existing keyed installation.

This is a local pilot update. Existing older records may contain only a generic stop reason; the original cause cannot be reconstructed reliably.
