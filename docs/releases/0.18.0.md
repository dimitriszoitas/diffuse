# Diffuse 0.18.0 — UX & Accessibility Reviewer

A single optional Claude reviewer now combines UX and accessibility guidance inside **Review with AI**. It reviews the captured page or a comparison, presents findings for approval, and links each guidance-based recommendation to its sources.

- 33 original UX checks informed by 30 public NN/g articles.
- 66 accessibility checks covering all 55 active WCAG 2.2 A/AA criteria, three labeled AAA enhancements, ARIA patterns and evaluation limits.
- Sources checked 24 October 2026, with versioned rules and evidence requirements. This is a reference snapshot, not a live feed or an article archive.
- **Visible observation**, **UX recommendation** and **Needs verification** distinguish what the captured evidence supports.
- Assessment labels and safe source links stay with accepted findings in HTML, Markdown and JSON exports.
- **Settings → AI → UX & accessibility review → Set up reviewer** creates one named reviewer in the connected Claude account. Existing reviewer versions update in place.
- Claude Opus 5.5 with Max effort, a separate per-review spending limit, restricted tools, and explicit failure instead of a silent second paid request.

A screenshot review cannot establish keyboard behavior, DOM semantics, screen-reader behavior, measured contrast or full WCAG conformance. Its reference library defines these checks, but unsupported tests remain unverified. The journey user and evaluator remain separate from this screenshot reviewer.
