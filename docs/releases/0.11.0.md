# Diffuse 0.11.0

Write feedback beside the element you are reviewing.

- Tap **C**, release it, and click: a pin and focused comment popover open on the page, even while the sidebar is open.
- Category and severity are compact dropdown badges at the top right.
- Write a comment and optional expected result. Title, component, and state fields are removed from the composer. Reproduction steps are collapsed until needed.
- Inspect the attached screenshot or add a short recording inside the same popover. Capture retries and recordings retain your text.
- The popover stays inside the viewport. The sidebar keeps review controls and provides **Return to comment**.
- Newly placed pins keep the clicked position within their element, including in exported/imported reviews.
- The Jira preview uses your configured Anthropic key and model to suggest a title from the full comment. Titles remain editable before tickets are created. Existing titles are preserved; a comment excerpt is used when AI is unavailable.

## Update

From an official **0.10.2** installation, replace the files in your existing Diffuse folder with this release, then click **Reload** in `chrome://extensions` and refresh the page being reviewed. Keep the same installation; do not uninstall it. The extension identity, saved reviews, and settings are retained.

For **0.10.1 or earlier**, export saved reviews first, keep the old installation intact, install this release separately, and import the reviews using **Load review**. Reconnect optional accounts and disable the old copy after checking the imports.

New installations: unzip **Diffuse-0.11.0.zip**, enable Developer mode in `chrome://extensions`, choose **Load unpacked**, and select the **Diffuse** folder. Jira sign-in remains available through **Settings → Jira connections → Connect Jira**.
