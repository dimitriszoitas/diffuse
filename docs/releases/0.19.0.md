# Diffuse 0.19.0 — Provider choice, clearer controls and journey reports

- Choose Anthropic or OpenAI for all new AI features. Independent keys, remember preferences, models and engines stay saved per provider.
- OpenAI supports direct reviews plus saved Journey User, Journey Evaluator and UX & Accessibility Reviewer agents using GPT-6.1 Sol with Max effort. Setup requires the user’s OpenAI API key and account access. OpenAI execution is fixture-tested; no live account inference was performed for this build.
- Existing journeys stay tied to their original provider. There is no automatic provider fallback. OpenAI agent amounts are estimated spending guards, not hard provider billing caps.
- One **Review with AI** entry contains screen review and journey testing. Both use consistent back navigation.
- Settings content is wider; selected navigation loses its side stripe; agent sections have proper padding. Popup hover uses a rounded background, load review uses an open-folder icon, and the viewport selector is compact.
- Keyboard focus brightens the control’s own boundary. Comment shortcuts can be configured, disabled and reset; a gear in the sidebar opens those settings.
- Reports now include a separate **Journeys** section with completed, stopped, blocked and interrupted attempts, including zero-comment reviews. Each journey shows its saved steps, reasons, results, execution status, page context, persona, target and stop reason when known. Retained recordings and screenshots are available alongside the steps.
- Older journey media can be cleared under the existing local storage budget, but step ledgers and notes are preserved until their review is deleted. Data removed by previous versions cannot be restored. Full HTML reports include journeys; portable JSON and Jira/GitHub exports retain their existing selected-finding scope.

Update the existing unpacked Diffuse folder and reload it in Chrome to retain its identity, reviews and settings. Refresh reviewed pages to load the new page controls.
