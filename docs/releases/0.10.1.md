# Diffuse 0.10.1

Diffuse now includes an optional dark appearance. Open **Settings → Appearance** and choose **Light**, **Dark**, or **System**. Light remains the default, and System follows changes to your device's appearance.

- A deep navy palette carries across the popup, sidebar, review notebook, settings, comparison controls, custom menus, and on-page comments.
- Open Diffuse views update immediately when the preference changes. Severity and category colors keep their meaning in both appearances.
- Appearance stays local to this Chrome profile. The reviewed website and original evidence remain unchanged; shared reviews do not contain your appearance preference.
- No new permissions are required. All existing review, Figma reference, and Jira functionality is preserved. Downloaded HTML reports retain their portable light presentation.

Download **Diffuse-0.10.1.zip**, replace the files in your existing installation folder, and choose **Reload** on the existing Diffuse card in Chrome's extensions page. Refresh reviewed pages afterward. Keeping the same installed folder preserves your extension ID and access to saved reviews.

The release ZIP contains **61 files**, each checked byte-for-byte against the extension source and setup documents. The case-study preview also passed keyboard and layout checks at desktop and phone sizes.
