# Diffuse 0.17.2

## Journey targets and clear stop reasons

- Replace the hard action limit with an action target. Passing the target never stops the journey.
- Show a separate action-efficiency score on completed attempts: target divided by actual actions, capped at 100. Unfinished attempts stay unscored; continuations score the current part only.
- Remove the default overall duration cutoff while retaining spending limits, request timeouts, no-progress checks and browser safeguards.
- Save partial recordings at their size or duration cap and continue collecting screenshots and step notes. Unexpected capture loss asks for guidance with a specific reason.
- Preserve and display the actual stop reason in results and discussion, including older recording stops when the saved recording identifies their cause.
- Support longer histories with bounded AI context, preserved original step numbers, and evaluator access to later evidence.
- Update existing Claude journey agents in place through Check journey agents; keep prior versions for saved journeys.

This is a local pilot update. It preserves the existing extension identity, reviews, evidence and settings. No old run is resumed automatically.
