# Diffuse 0.16.0

## Help the journey when it gets stuck

A blocked journey now asks for guidance in chat, for example: “I can’t find the remaining recipes. What should I try?” The question stays with the saved steps and recording. Older blocked runs also offer a help conversation.

Write an answer and classify the blocker:

- **Issue with the experience**
- **AI missed something**
- **Not sure yet**

Then choose **Stop journey** or **Continue**. Stop saves the assessment and optional guidance without another AI call. Continue saves the answer and uses it as instructions for a linked continuation from the current page. It inherits the journey settings and preserves the earlier evidence.

The classification records your assessment of this blocker separately from the AI’s original findings and scores. It does not automatically create an issue or rewrite unrelated findings. Login, access, payment and other sensitive-action restrictions remain in force.

If continuing fails, your answer remains saved. Retrying reuses the saved response and does not create a duplicate continuation. Closing the help conversation does not force it open again on each refresh.

## Update

Replace the files in your existing official Diffuse folder, reload Diffuse at `chrome://extensions`, and refresh the reviewed page. Keep the existing installation to retain saved reviews, journeys, connections, and settings.
