# Diffuse 0.20.0

Review with AI now includes an optional **Interactive audit** powered by a local Playwright MCP companion.

- Pair the helper, open a dedicated local browser, sign in if needed, then explicitly collect evidence from its current page.
- Inspect computed typography, colors, spacing and radii, with counts and examples from a bounded sample of rendered elements.
- Run axe-core accessibility checks, sample hover changes and keyboard Tab destinations, and capture local screenshot evidence. Incomplete checks and sampling limitations remain visible.
- Save completed, stopped and interrupted audits in a separate Interactive audits section of Reports, including collector steps and their descriptions.
- Optionally send a bounded text-only evidence summary to the selected Anthropic or OpenAI model for one analysis request. Screenshots, cookies, API credentials and raw browser logs are excluded from that summary. Screenshots remain on this device unless explicitly exported or shared as an accepted comment.
- Add an AI finding to a review as a comment with the page screenshot, or download a standalone HTML audit report. This does not invent an exact element pin.

The companion runs on 127.0.0.1:8932 with a local pairing token and an allowlisted extension origin. It uses a dedicated browser profile; it does not attach to personal Chrome tabs. No cloud browser subscription is needed.

This first release audits one prepared page and sampled interaction states. It does not click controls, submit forms, crawl routes, record video or replace the existing journey runner. A browser can still make normal site requests and execute page behavior. Automated accessibility findings do not establish full WCAG conformance. The collection timeout preserves partial evidence; it is separate from journey action targets.
