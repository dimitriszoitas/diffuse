# Diffuse 0.15.0

## Configure the user and the review

Before a journey, describe who is trying the task. Adjust technical confidence, product familiarity, task familiarity, and willingness to keep trying. The saved profile guides decisions, assessment, and follow-up discussion. It is an AI simulation, not research with real participants.

Choose what AI should check: task completion, discoverability and clarity, feedback and recovery, interaction states, accessibility, and layout consistency. Unobserved or unsupported checks must remain untested. Execution duration is not a measure of human hesitation.

Choose balanced or thorough exploration, add instructions, and explicitly allow moving the test records needed for your task when appropriate. Lists and dialogs expose their own scroll targets so the journey can inspect more than the initially visible items.

## Discuss and continue

**Ask AI** opens a chat with the journey or selected step as context. Keep asking follow-up questions in the same conversation, inspect cited steps, and fork a proposed alternative route.

**Continue journey** is available for stopped, blocked, and inconclusive runs. Add instructions and continue from the currently open page on the same website, with prior steps as context. Diffuse does not navigate back to the start or reset application data. The continuation has its own recording, steps, and action count; the previous run stays saved.

**Try another route** still starts again at the original starting page. Paused runs retain the ordinary **Resume** action.

## Fixes

Fixed the first-open journey error, “Cannot read properties of null (reading 'updatedAt')”, when no saved run exists.

## Update

Replace the files in your existing official Diffuse folder, reload Diffuse at `chrome://extensions`, and refresh the reviewed page. Keep the existing installation to retain saved reviews, journeys, connections, and settings.
