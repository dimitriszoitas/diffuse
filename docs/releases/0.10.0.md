# Diffuse 0.10.0

AI reviews can now use a Figma frame as a design reference. Connect the desktop MCP server in **Settings → Figma reference**, then paste a frame or layer link into **AI review → Figma frame** or the review instructions. The link must include a `node-id`; whole-file links are not supported.

- Diffuse reads available design context, variables, and inline screenshots using supported read-only tools. It sends the reference with the captured page to the configured Anthropic model when the reviewer runs AI review.
- Accepted findings retain the Figma URL, captured context, and up to two reference images in shared JSON reviews, HTML/Markdown exports, and Jira handoffs.
- Custom compatible Streamable HTTP servers can use HTTPS and an optional bearer token. Tokens stay in trusted extension storage, use session storage by default, and are not reused when the endpoint changes.
- Cancellation and session changes stop the review without publishing results into another session. Failed reference retrieval does not silently fall back to an audit without the reference.

Keep the matching file open in **Figma desktop**, with the Desktop MCP server enabled in Dev Mode. The default endpoint is `http://127.0.0.1:3845/mcp`. Figma's hosted OAuth connection is not supported. Asset links returned by the server are not downloaded; text-only references remain usable with a visible limitation when no inline screenshot is supplied.
